# If I Disappear

When a parent leaves Sri Lanka to work abroad, the house still has to run. If I Disappear turns one
walk through the house into checked, bilingual (English and Sinhala) handover steps, and proves,
before they leave, that someone at home can really do each job.

Press **Try the sample home**: no sign-up and no key. Every model output in the sample is a real,
recorded run of Muse Spark 1.3, Muse Wonder and SAM 3.1, and every check runs live.

When this Space has a Meta Model API key (kept as a secret in its settings), a real home starts at
`/start`, with the invite code from whoever runs it.

Built for the Meta Global AI Developer Hackathon 2026 by Nipun Dilshan Senevirathne.
Source code, evaluation and documents: see the project repository.
